Yinglong (应龙)

## 软件简介
Yinglong (应龙) 是一款基于 Go 语言开发的安全命令执行与管理系统。它旨在提供一个受控的环境来执行系统命令，通过引入安全审计、敏感信息注入和配置管理等功能，确保命令执行的合规性与安全性。该系统支持对执行的命令进行黑名单过滤，并能安全地管理和注入敏感参数，同时具备详细的日志记录能力。

## 主要功能

1.  **安全命令执行**: 提供一个框架来执行系统命令，并集成多种安全机制。
2.  **命令审计**: 通过黑名单机制，对即将执行的命令进行审查，阻止未经授权或不安全的命令。支持命令本身和涉及文件路径的黑名单。
3.  **敏感信息注入**: 实现安全的敏感信息（如密码）管理和注入机制，避免敏感信息在命令执行过程中直接暴露。
4.  **详细日志记录**: 记录所有命令执行相关的操作和结果，便于追踪、审计和故障排除。日志文件为 `yl_history.log`。
5.  **模块化配置管理**: 支持从外部配置文件（如 `password.json` 和 `deny.json`）加载敏感参数和审计规则。
6.  **外部系统集成支持**: 具备与外部系统 `openclaw` 交互或为其生成配置规则的能力（通过 `cmd/ruler` 模块）。
7.  **配置监控 (规划中)**: 计划实现对 `openclaw` 配置文件变化的监控功能（通过 `cmd/watcher` 模块）。

## 技术特性

*   **Go 语言实现**: 利用 Go 语言的高并发、高性能特性，确保命令执行的效率和稳定性。
*   **上下文管理**: 使用 Go 的 `context` 包进行命令执行的超时控制。
*   **文件系统操作**: 灵活处理文件路径，创建必要的日志和配置目录。
*   **并发处理**: 利用 Goroutine 和 WaitGroup 管理并发任务，如并行初始化注入器和审计器。
*   **命令行应用**: 作为独立的命令行工具运行，易于部署和集成。

## 软件架构

Yinglong 项目采用模块化设计，主要包含以下组件：

*   **`cmd/command`**: 核心命令行应用，负责程序的启动、初始化、参数解析、命令审计、注入和执行流程。
*   **`cmd/mcp`**: （待实现）预留模块，可能用于消息控制协议或其他特定功能。
*   **`cmd/ruler`**: 负责生成或处理 `openclaw` 相关的规则文件。
*   **`cmd/watcher`**: （规划中）旨在监控 `openclaw` 配置文件的变化。
*   **`internal`**: 内部核心库，包含实现审计 (`auditor`)、命令执行 (`executor`)、敏感信息注入 (`injector`)、日志 (`logger`)、配置读取 (`setting`) 和通用工具 (`util`) 等功能的模块。
*   **`config`**: 存放程序的配置文件，如 `deny.json` (命令黑名单) 和 `password.json` (敏感参数)。
*   **`log`**: 存放程序运行日志。
